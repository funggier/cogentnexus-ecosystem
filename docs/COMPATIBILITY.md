# Compatibility

Only combinations exercised together should be listed here.

| Ecosystem | Staged Capability Loop | CogentNexus Core | OpenClaw |
| --- | --- | --- | --- |
| 0.1.x | 1.x | 0.6.3 or newer | 2026.7.1-2 or newer |

The tested baseline uses the CogentNexus managed `AGENTS.md` block and the four-lane staged admission policy. Older CogentNexus releases can still load the companion skill, but their installer does not guarantee workspace-wide activation.
