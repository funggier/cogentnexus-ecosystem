# CogentNexus Ecosystem v0.2.0

v0.2.0 is the clean ecosystem baseline aligned with CogentNexus Core v0.8.x.

## What changed

- removes the old ordering that loaded CogentNexus Core before request-lane admission;
- defines DIRECT / LOOKUP / ACTION / STAGED as the first model-side routing decision;
- keeps DIRECT conversation lightweight even when Ticket-first continuity is active;
- loads the `cogentnexus` durable machinery only for STAGED work or explicit managed recovery;
- documents MANAGED / PASSTHROUGH / MAINTENANCE as Host-level semantics owned by Core;
- updates integration and compatibility documentation;
- makes the installer require the Core v0.8 Host surface (`host.py` + managed policy template) before installing the companion;
- adds tests that fail if the bootstrap inversion is reintroduced.

## Compatibility

Tested baseline:

- CogentNexus Ecosystem 0.2.x
- Staged Capability Loop 1.x
- CogentNexus Core 0.8.x
- OpenClaw 2026.7.1-2 or newer

## Key invariant

Ticket-first continuity protects accepted work, but it does not decide execution depth. A greeting should remain DIRECT; consequential interruption-prone work may enter STAGED durable execution.
