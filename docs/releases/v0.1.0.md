# CogentNexus Ecosystem v0.1.0

Initial public ecosystem release.

- Publishes `staged-capability-loop` as the first official CogentNexus companion skill.
- Adds DIRECT, LOOKUP, ACTION, and STAGED admission lanes.
- Provides an idempotent installer that preserves and backs up user-authored `AGENTS.md` content.
- Requires CogentNexus Core to be installed first and documents the responsibility boundary.
- Declares CogentNexus Core and Staged Capability Loop as one CogentNexus Ecosystem suite for OpenClaw.
